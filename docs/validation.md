# Проверка основы — 14 октября 2026

В текущей облачной машине выполнены:

- `bash scripts/setup_cloud.sh`: повторная установка без изменения lockfiles и без перезаписи локальной .env; сборка Docker-образов.
- `make check`: Go tests, go vet, Go build, 3 Vue-теста, проверка TypeScript и production-сборка Vite.
- `make integration`: повторные миграции, готовность приложения, запись в своей организации, отказ cross-tenant FK, запрет изменения истории миграций и создания таблиц ролью приложения.
- Полный `make up`: PostgreSQL 17, процесс миграций, Go API и Nginx/Vue.
- Новая пустая тестовая база в отдельном Compose-проекте: создание DB-ролей и два успешных запуска миграций. Временные контейнеры остановлены и удалены.
- 2 Playwright-сценария с установленным Chromium: desktop 1366 px и mobile 320 px, готовность базы через интерфейс, переход в банк вопросов, перезагрузка маршрута и отсутствие горизонтальной прокрутки. Проверены Vite и контейнерный интерфейс.
- Управляемая остановка PostgreSQL: `/healthz` продолжал возвращать 200, `/readyz` вернул 503; после запуска базы готовность восстановилась.
- Проверены служебный API через Nginx, HTML, CSP и заголовок nosniff.
- Три приложенных исходных документа сохранены побайтово без изменений; локальные пароли, данные PostgreSQL, зависимости и сборки исключены из Git.

Обычный `go test ./...` пропускает DB-тест без переменных; его фактический успешный запуск подтверждён отдельно через `make integration`.

Не выполнялись: GitHub Actions на сервере GitHub, проверки Safari/Firefox, нагрузочные испытания, промышленное размещение, публикация снимка среды и восстановление в новой задаче. Предметные приёмочные сценарии ТЗ будут проверяться по мере реализации функций.
